# 화상 화이트보드

2명이 함께 사용하는 화상통화 + 텍스트 채팅 + PDF 화이트보드 앱입니다.

---

## 시작하기

### 1. 의존성 설치

```bash
npm install
```

### 2. 서버 실행

```bash
npm start
```

### 3. 브라우저 접속

```
http://localhost:3000
```

---

## 입장 방법

1. 브라우저에서 위 주소를 엽니다.
2. **닉네임**과 **방 이름**을 입력합니다.
3. **입장하기** 버튼을 클릭합니다.
4. 상대방도 동일한 **방 이름**으로 입장하면 자동으로 연결됩니다.

> 방 하나에 최대 **2명**까지 입장 가능합니다.

---

## 기능 안내

### 화상통화

| 버튼 | 기능 |
|---|---|
| 🎤 마이크 | 클릭하면 마이크 켜기/끄기 |
| 📷 카메라 | 클릭하면 카메라 켜기/끄기 |

- 상대방이 입장하면 자동으로 화상통화가 시작됩니다.
- 왼쪽 패널 위쪽이 상대방 화면, 아래쪽이 내 화면입니다.

### 텍스트 채팅

- 왼쪽 패널 하단의 입력창에 메시지를 입력하고 **전송** 버튼 또는 `Enter`를 누릅니다.

### 화이트보드

| 도구 | 설명 |
|---|---|
| ✏️ 펜 | 자유롭게 필기 |
| 🧹 지우개 | 원하는 부분만 지우기 |
| 색상 | 컬러 피커로 펜 색상 변경 |
| 굵기 | 슬라이더로 펜/지우개 크기 조절 |
| 🗑️ 지우기 | 전체 보드 초기화 (상대방 화면도 함께 지워짐) |

- 그림은 실시간으로 상대방 화면에 동기화됩니다.
- 나중에 입장해도 현재 보드 상태를 자동으로 받습니다.

### PDF 공유

1. 툴바의 **📄 PDF** 버튼을 클릭합니다.
2. PDF 파일을 선택하면 상대방에게 자동으로 공유됩니다.
3. `◀` / `▶` 버튼으로 페이지를 넘기면 상대방 화면도 함께 이동합니다.
4. PDF 위에 바로 필기할 수 있습니다.

## 키보드 단축키

| 단축키 | 기능 |
|---|---|
| `P` | 펜 선택 |
| `E` | 지우개 선택 |
| `←` | PDF 이전 페이지 |
| `→` | PDF 다음 페이지 |
| `Enter` | 채팅 메시지 전송 |

## 외부에서 접속하는 방법 (ngrok)

같은 Wi-Fi가 아닌 다른 장소에서 접속하려면 ngrok을 사용합니다.

### ngrok 설치

```bash
# Windows (winget)
winget install ngrok

# 또는 https://ngrok.com/download 에서 직접 다운로드
```

### 외부 주소 생성

서버를 실행한 상태에서 별도 터미널을 열고:

```bash
ngrok http 3000
```

출력되는 `https://xxxx.ngrok-free.app` 주소를 상대방에게 공유하면 됩니다.
