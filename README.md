# 화상 화이트보드

2명이 함께 사용하는 화상통화 + 텍스트 채팅 + PDF 화이트보드 앱입니다.

---

## 시작하기

### 1. 의존성 설치

```bash
npm install
```

### 2. 서버 실행

```bash
npm start
```

### 3. 브라우저 접속

```
http://localhost:3000
```

---

## 입장 방법

1. 브라우저에서 위 주소를 엽니다.
2. **닉네임**과 **방 이름**을 입력합니다.
3. **입장하기** 버튼을 클릭합니다.
4. 상대방도 동일한 **방 이름**으로 입장하면 자동으로 연결됩니다.

> 방 하나에 최대 **2명**까지 입장 가능합니다.  
> 먼저 입장한 사람이 **방장**이 됩니다.

---

## 기능 안내

### 화상통화

- 상대방이 입장하면 자동으로 화상통화가 시작됩니다.
- 왼쪽 패널 위쪽이 상대방 화면, 아래쪽이 내 화면입니다.

### 미디어 설정 (⚙️)

| 항목 | 설명 |
|---|---|
| 카메라 | 장치 선택 / 켜기·끄기 |
| 마이크 | 장치 선택 / 켜기·끄기 / 음량 조절 |
| 스피커 | 장치 선택 / 음량 조절 |

### 텍스트 채팅

- 왼쪽 패널 하단 입력창에 메시지 입력 후 **전송** 또는 `Enter`

### 화이트보드

| 도구 | 설명 |
|---|---|
| ✏️ 펜 | 자유선 / 직선 / 수직·수평 고정선 |
| 🧹 지우개 | 원하는 부분만 지우기 |
| 🔷 도형 | 사각형·삼각형·원 (선 / 채우기) |
| 색상 | 검정·흰색·빨강·파랑·주황·보라·노랑 |
| 굵기 | 슬라이더로 조절 |
| 🗑️ 전체 지우기 | 방장만 가능 |

- 그림은 실시간으로 상대방 화면에 동기화됩니다.
- 나중에 입장해도 현재 보드 상태를 자동으로 받습니다.
- `Ctrl+Z` 로 실행 취소 가능합니다.

### PDF 공유

1. 툴바의 **📄 PDF** 버튼을 클릭합니다.
2. PDF 파일을 선택하면 상대방에게 자동으로 공유됩니다.
3. `◀` / `▶` 버튼으로 페이지를 넘기면 상대방 화면도 함께 이동합니다.
4. PDF 위에 바로 필기할 수 있습니다.
5. 확대/축소 시 고해상도로 재렌더링됩니다.

### 웹 공유 (🌐)

- 하단 탭에서 **웹** 모드로 전환하면 URL을 입력해 웹페이지를 공유할 수 있습니다.

### 방장 전용 기능 (👑)

먼저 입장한 사람이 방장이 됩니다. 방장이 나가면 남은 사람이 자동으로 방장이 됩니다.

| 기능 | 설명 |
|---|---|
| 전체 지우기 | 화이트보드 전체 초기화 |
| 마이크 음소거 | 상대방 비디오 하단 🎤 버튼 |
| 스피커 음량 | 상대방 비디오 하단 슬라이더 |
| 상대방 기기 설정 | 상대방 비디오 하단 ⚙️ → 카메라·마이크·스피커 장치 변경 |

### 녹화 (⏺)

- 헤더의 녹화 버튼으로 화면 + 오디오를 함께 녹화합니다.

## 외부에서 접속하는 방법 (Cloudflare Tunnel)

같은 Wi-Fi가 아닌 다른 장소에서 접속하려면 Cloudflare Tunnel을 사용합니다.

### cloudflared 설치

```bash
# Windows (winget)
winget install Cloudflare.cloudflared

# 또는 https://developers.cloudflare.com/cloudflare-one/connections/connect-networks/downloads/ 에서 직접 다운로드
```

### 외부 주소 생성

서버를 실행한 상태에서 별도 터미널을 열고:

```bash
cloudflared tunnel --url http://localhost:3000
```

출력되는 `https://xxxx.trycloudflare.com` 주소를 상대방에게 공유하면 됩니다.

> **주의**: 매번 실행마다 새로운 주소가 생성됩니다.  
> **주의**: 카메라/마이크는 HTTPS에서만 작동하므로 반드시 `https://` 주소를 사용하세요.

## Electron 데스크탑 앱

브라우저 없이 독립 실행 프로그램으로 사용할 수 있습니다.

### 개발 모드 실행

```bash
npm run electron
```

### 빌드 (.exe)

```bash
npm run build
```

빌드 결과물은 `dist/win-unpacked/화상 화이트보드.exe`에 생성됩니다.

> **참고**: 두 사람이 각자 앱을 실행하면 서로 다른 서버에 연결되므로 통화가 되지 않습니다.  
> 한 명이 서버를 실행하고 Cloudflare Tunnel로 공유하거나, 서버를 클라우드에 별도로 배포해야 합니다.

## 파일 구조

```
white-board/
├── main.js          # Electron 메인 프로세스
├── server.js        # Node.js 서버 (시그널링 + 채팅 + 보드 동기화)
├── package.json
└── public/
    ├── index.html   # 화면 구조
    ├── style.css    # 스타일
    └── client.js    # WebRTC + 화이트보드 + PDF 로직
```

## 기술 스택

- **서버**: Node.js, Express, Socket.io
- **화상통화**: WebRTC (P2P) + TURN 서버 (openrelay.metered.ca)
- **PDF 렌더링**: PDF.js
- **시그널링**: Socket.io
- **데스크탑**: Electron
