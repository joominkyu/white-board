# 화상 화이트보드

2명이 함께 사용하는 화상통화 + 텍스트 채팅 + 화이트보드 + PDF 공유 앱입니다.

---

## 시작하기

### 1. 의존성 설치

```bash
npm install
```

### 2. 서버 실행

```bash
npm start
```

### 3. 브라우저 접속

```
http://localhost:3000
```

---

## 입장 방법 (봄노트 실시간 수업)

화이트보드는 봄노트의 **실시간 수업 애드온**으로 동작합니다. 주소로 직접 들어올 수 없고, 봄노트가 발급한 입장 토큰이 있어야 합니다.

1. 선생님(과외 계정)이 봄노트 학생 탭에서 학생의 **[수업]** 버튼을 누르면 화이트보드가 새 탭으로 열립니다.
2. 학생 대시보드에 **[수업 입장]** 배너가 표시되고, 누르면 같은 수업에 입장합니다.
3. 한 수업에 최대 **2명**(선생님 1, 학생 1)이며, 방장은 항상 선생님입니다.

> 네트워크가 잠깐 끊겨도 자동으로 다시 연결되고, 모두 나가도 보드 내용은 **10분간** 서버에 보관됩니다.  
> 사용 시간(두 사람이 모두 접속한 시간)은 1분마다 봄노트로 보고되어 월 한도에 반영됩니다.

## 기능 안내

### 화상통화

- 상대방이 입장하면 WebRTC P2P로 자동 연결됩니다.
- 왼쪽 패널 위쪽이 상대방 화면, 아래쪽이 내 화면입니다.

| 버튼 | 기능 |
|---|---|
| 🎤 마이크 | 마이크 켜기/끄기 |
| 📷 카메라 | 카메라 켜기/끄기 |
| ⚙️ 설정 | 카메라·마이크·스피커 장치 선택 및 볼륨 조절 |

### 미디어 설정 (⚙️)

| 항목 | 설명 |
|---|---|
| 카메라 | 장치 선택 / 켜기·끄기 |
| 마이크 | 장치 선택 / 켜기·끄기 / 음량 조절 |
| 스피커 | 장치 선택 / 음량 조절 |

### 텍스트 채팅

- 왼쪽 패널 하단 입력창에 메시지 입력 후 **전송** 또는 `Enter`를 누릅니다.

### 화이트보드

| 도구 | 설명 |
|---|---|
| ✏️ 펜 (자유) | 자유 곡선 필기 |
| ✏️ 펜 (직선) | 직선 그리기 |
| ✏️ 펜 (스냅) | 수평·수직 스냅 직선 |
| 🔷 도형 | 사각형·삼각형·원 (선 / 채우기) |
| 🧹 지우개 | 원하는 부분만 지우기 |
| ↩️ 실행취소 | 현재 페이지에서 내가 그린 마지막 획 되돌리기 (상대 획은 유지) |
| 🗑️ 전체 지우기 | 현재 페이지 필기 초기화 (방장만 가능) |
| 색상 | 컬러 피커로 펜 색상 변경 |
| 굵기 | 슬라이더로 펜/지우개 크기 조절 |
| 🔍 줌 | 보드 확대/축소 |

- 모든 드로잉은 실시간으로 상대방 화면에 동기화됩니다. 화면 크기가 달라도 같은 위치에 그려집니다.
- 나중에 입장해도 PDF·현재 페이지·필기를 서버에서 그대로 받습니다.
- `Ctrl+Z` 로 실행 취소 가능합니다.

### PDF 공유

1. 툴바의 **📄 PDF** 버튼을 클릭합니다.
2. PDF 파일을 선택하면 서버에 업로드되고 상대방에게 자동으로 공유됩니다 (최대 50MB).
3. `◀` / `▶` 버튼으로 페이지를 넘기면 상대방 화면도 함께 이동합니다.
4. PDF 위에 바로 필기할 수 있습니다. 필기는 페이지별로 저장되어 페이지를 넘겼다 돌아와도 유지됩니다.
5. 확대/축소 시 PDF와 필기 모두 고해상도로 다시 그려집니다.

### 웹 공유 (🌐)

- 하단 탭에서 **웹** 모드로 전환하면 URL을 입력해 웹페이지를 공유할 수 있습니다.
- URL을 입력하면 상대방 화면에서도 동일한 페이지로 이동합니다.

### 방장 전용 기능 (👑)

먼저 입장한 사람이 방장이 됩니다. 방장이 나가면 남은 사람이 자동으로 방장이 됩니다.

| 기능 | 설명 |
|---|---|
| 전체 지우기 | 화이트보드 전체 초기화 |
| 마이크 음소거 | 상대방 비디오 하단 🎤 버튼 |
| 스피커 음량 | 상대방 비디오 하단 슬라이더 |
| 상대방 기기 설정 | 상대방 비디오 하단 ⚙️ → 카메라·마이크·스피커 장치 변경 |

### 녹화 (⏺)

- 헤더의 **녹화** 버튼으로 화이트보드 + 양쪽 영상 + 오디오를 로컬에 녹화합니다.
- 녹화 중 타이머가 표시되며, 중지 시 파일로 저장됩니다.
- 탭을 다른 곳으로 옮기면 브라우저 제한으로 녹화 화면이 느리게 갱신될 수 있습니다.

## 서버 배포 (Railway) 및 TURN 설정

서버는 Railway에 배포해서 사용합니다. 방 상태(PDF·필기)는 서버 메모리에 저장되므로 **인스턴스는 1개**로 유지하세요.

### TURN 서버 (Cloudflare)

회사·학교 망이나 모바일 데이터처럼 P2P 직접 연결이 막힌 환경에서는 TURN 중계 서버가 있어야 화상 연결이 됩니다.
Railway는 UDP 포트를 열 수 없어 TURN을 직접 운영할 수 없으므로 Cloudflare TURN을 사용합니다.

1. [Cloudflare 대시보드](https://dash.cloudflare.com/) → **Realtime → TURN Server**에서 TURN 키를 생성합니다.
2. 발급된 **Turn Token ID**와 **API Token**을 Railway 서비스의 환경 변수로 등록합니다.

```
CLOUDFLARE_TURN_KEY_ID=...
CLOUDFLARE_TURN_API_TOKEN=...
```

### 봄노트 연동 (필수)

```
LIVE_CLASS_SECRET=...   # 봄노트 백엔드의 LIVE_CLASS_SECRET과 같은 값
BOMNOTE_API_URL=...     # 봄노트 백엔드 주소
```

봄노트 백엔드에는 같은 `LIVE_CLASS_SECRET`과 이 서버 주소(`LIVE_CLASS_URL`)를 설정합니다.

설정하지 않으면 공개 STUN/TURN 서버로 동작하며, 일부 네트워크에서는 연결이 안 될 수 있습니다.

## 외부에서 접속하는 방법 (Cloudflare Tunnel)

같은 Wi-Fi가 아닌 다른 장소에서 접속하려면 Cloudflare Tunnel을 사용합니다.

### cloudflared 설치

```bash
# Windows (winget)
winget install Cloudflare.cloudflared
```

또는 [Cloudflare 공식 다운로드 페이지](https://developers.cloudflare.com/cloudflare-one/connections/connect-networks/downloads/)에서 직접 다운로드

### 외부 주소 생성

서버를 실행한 상태에서 별도 터미널을 열고:

```bash
cloudflared tunnel --url http://localhost:3000
```

출력되는 `https://xxxx.trycloudflare.com` 주소를 상대방에게 공유하면 됩니다.

> 계정 없이 임시 터널을 사용할 수 있습니다. 영구 도메인이 필요하면 [Cloudflare Zero Trust](https://dash.cloudflare.com/)에서 터널을 등록하세요.  
> **주의**: 매번 실행마다 새로운 주소가 생성됩니다.  
> **주의**: 카메라/마이크는 HTTPS에서만 작동하므로 반드시 `https://` 주소를 사용하세요.

## Electron 데스크탑 앱

브라우저 없이 독립 실행 프로그램으로 사용할 수 있습니다.

### 환경 변수 설정

Electron 앱은 접속할 서버 주소를 `.env` 파일에서 읽습니다.

```bash
# .env.example을 복사해서 생성
cp .env.example .env
```

`.env` 파일을 열고 실제 서버 주소를 입력하세요:

```
SERVER_URL=https://your-server.up.railway.app
```

> `.env` 파일은 git에 포함되지 않습니다. 배포된 서버 주소는 본인이 직접 입력해야 합니다.

### 개발 모드 실행

```bash
npm run electron
```

### 빌드 (.exe)

```bash
npm run build
```

빌드 결과물은 `dist/win-unpacked/화상 화이트보드.exe`에 생성됩니다.

> **참고**: `.env`는 빌드 시 앱에 함께 포함됩니다. 서버 주소를 바꾸면 다시 빌드하세요.  
> 앱 안에서 열리는 새 창(웹 공유 팝업, 새 탭 링크)은 기본 브라우저로 열립니다.
